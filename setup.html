⚡ Relay — نصب سریع

این صفحه کمکت می‌کنه بدون ترمینال و بدون نصب هیچ برنامه‌ای، «توکن گوگل» و کلیدهای لازم برای نصب Relay رو بگیری. همه‌چیز فقط توی مرورگر خودت انجام می‌شه؛ هیچ اطلاعاتی به هیچ سروری فرستاده نمی‌شه و این صفحه هیچ‌چیز رو ذخیره نمی‌کنه.

۱اعتبارنامه‌ی اپ Antigravity

دو مقدار زیر مال اپ رسمی Antigravity هستن (توی راهنمای پروژه — بخش Client credentials — نوشته از کجا پیداشون کنی). این‌جا واردشون کن؛ فقط توی همین تب استفاده می‌شن.

❓ این دو تا رو از کجا پیدا کنم؟

اول یه خیال راحت: این دو مقدار، رمز شخصی تو نیستن — اعتبارنامه‌ی عمومیِ اپ دسکتاپ Antigravity هستن که گوگل همراه خود اپ پخش کرده. دو راه برای گرفتنشون هست:

راه ۱ — از اپ رسمی Antigravity (سریع‌تر):
۱. اپ رسمی Antigravity رو روی کامپیوترت نصب کن و یه بار باهاش وارد شو.
۲. این دو مقدار داخل فایل‌های نصب اپ هستن: توی پوشه‌ی نصب برنامه، عبارت apps.googleusercontent.com رو جست‌وجو کن؛ رشته‌ای که پیداش می‌کنی Client ID ـه و مقدار کناریش که با GOCSPX شروع می‌شه Client Secret ـه.
۳. همین دو تا رو این‌جا پیست کن. (توی سورس روترهای متن‌باز مثل 9Router هم همین مقادیر برای پرووایدر Antigravity هست.)

راه ۲ — ساخت اعتبارنامه‌ی شخصی (رسمی‌ترین راه)، قدم‌به‌قدم:
۱. برو به console.cloud.google.com و با حسابت وارد شو.
⚠️ اگه گفت «Google Cloud access blocked» و ازت فعال‌کردن ورود دومرحله‌ای خواست، تعجب نکن؛ برای همه اجباریه: دکمه‌ی Enable MFA رو بزن و از بخش Security گزینه‌ی ورود دومرحله‌ای (2-Step Verification) رو با اپ Authenticator روشن کن، چند دقیقه صبر کن و صفحه رو رفرش کن.
۲. اگه پروژه نداری: از منوی انتخاب پروژه (بالای صفحه) بزن New Project، یه اسم بده (مثلاً Relay) و Create کن — بعد مطمئن شو همون پروژه بالای صفحه انتخاب شده.
۳. از کارت APIs & Services برو به OAuth consent screen و دکمه‌ی Get started رو بزن: اسم دلخواه (مثلاً Relay)، ایمیل خودت برای پشتیبانی، ‏Audience روی External و آخر Create.
۴. حالا برو به Credentials ← دکمه‌ی + Create Credentials ← OAuth client ID.
۵. توی Application type حتماً گزینه‌ی Desktop app رو انتخاب کن. اسمش هر چی می‌تونه باشه (فقط یه برچسبه). تیکِ «Use this client for an AI-powered agent» رو نزن. دکمه‌ی Create رو بزن.
۶. پنجره‌ای باز می‌شه با Client ID و Client Secret — جفتش رو کپی کن و این‌جا پیست کن.
⚠️ سکرت رو همون لحظه یه جای امن ذخیره کن: گوگل دیگه سکرت‌های قبلی رو نشون نمی‌ده (فقط ماسک‌شده می‌بینیش). اگه گمش کردی اشکالی نداره: توی صفحه‌ی کلاینت دکمه‌ی Add secret یه سکرت جدید می‌سازه — اون رو فوراً کپی کن و همه‌جا جایگزین کن. توکن هم خراب نمی‌شه، چون توکن به خود کلاینت وصله نه به سکرت خاص. وقتی با سکرت جدید همه‌چیز کار کرد، سکرت قدیمی رو Disable و Delete کن.
۷. وقتی با «ورود با گوگل»ی این صفحه لاگین می‌کنی، چون اپ خودت در حالت تست (Testing) ـه، فقط اکانت‌هایی می‌تونن وارد شن که «تستر» باشن: از منوی Google Auth Platform ← Audience بخش Test users، ایمیلی که می‌خوای باهاش وارد شی رو Add کن. وگرنه ارور 403: access_denied می‌گیری.
۸. وسط لاگین یه صفحه میاد «Google hasn't verified this app» — چون اپ خودته، Continue رو بزن.
۹. صفحه‌ی بعد، ازت می‌خواد دسترسی‌ها رو انتخاب کنی: هر سه تیک رو بزن (بالای لیست Select all هست) — مخصوصاً دسترسی داده‌های Google Cloud؛ بدون اون، توکن صادر می‌شه ولی رله باهاش جواب نمی‌گیره.
۱۰. بعد از تأیید، مرورگر می‌ره به یه آدرس localhost که باز نمی‌شه — طبیعیه! کل آدرس رو از نوار آدرس کپی کن و برگرد این‌جا توی کادر مرحله‌ی ۲ پیست کن. ⚠️ عجله کن: کدی که توی آدرسه یه‌بارمصرفه و حدود ۱۰ دقیقه عمر داره؛ اگه دیر شد، فقط کافیه دوباره «ورود با گوگل» رو بزنی.

۲ورود با گوگل

دکمه رو بزن، با اکانتی که می‌خوای Relay روش کار کنه وارد شو (توصیه: اکانت جدا، نه اصلی) و اجازه بده. بعد گوگل به یه آدرس localhost می‌فرستدت که باز نمی‌شه — طبیعیه! کل آدرس رو از نوار آدرس مرورگر کپی کن و این‌جا پیست کن.

۳پک نصب تو آماده‌ست 🎉

این مقادیر رو موقع نصب توی Vercel وارد می‌کنی. کلید Relay و پسورد داشبورد رو خودکار برات ساختم. این صفحه رو تا تموم شدن نصب نبند و مقادیر رو جای امن نگه دار.

حالا نصب با یک کلیک:

دکمه‌ی زیر پروژه رو توی Vercel خودت می‌سازه و ازت می‌خواد همین مقادیر رو وارد کنی (به‌علاوه‌ی Client ID و Secret قدم ۱). بعد از Deploy، آدرس سرویس تو می‌شه: https://<پروژه‌ت>.vercel.app/v1
